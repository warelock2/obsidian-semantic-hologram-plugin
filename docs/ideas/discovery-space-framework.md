## What the system is, at each level:

- **Node** = snapshot of a thought (atomic, portable, self-contained: carries its own `characteristics:`, `groups:`, `::` edges in-file, not in an external index).
- **Hologram** = snapshot of thinking (constellation of nodes + typed edges + routes).
- **Table spread (child hologram)** = persistent unit of exchange. Digital CWD + Canvas view = instant spread; Luhmann's physical spread dissolved, ours does not have to.
- **Discovery space** = what the whole system provides: a multidimensional, holographic space where cross-domain novelty can emerge — *space for novelty, not a guarantee*.

## The two-layer equation

- `emulsification(zk) = Semantic Holograms` — the intuitive, combinable layer.
- `Binswanger(emulsification(zk)) = Semantic Holograms grounded in objective reality and reason` — `characteristics:` + `all-genera.py` genera detection/selection + objective sources (`lends-gravitas-to` + evidence audit).
- Both layers renderable (Canvas, nD layers) and auditable (evidence audit, derivation check, rule 22).

So the system digitally provides: rendering, auditing, multidimensionality, exchange — with the possibility of metaphysical and epistemological fortitude and grounding.

## Emulsification

The enabling mechanism that turns the table spread from transient arrangement (Luhmann's dissolved spread) into a persistent, exchangeable unit. Reversible combination without loss: two sets viewed together (union on Canvas); each set brings its own edges; the emulsion is the view, not a file operation. Merge-back into the parent is the decay-resolution mechanism — the trail erases, the signal persists in the master; what does not survive translation into the parent's vocabulary was noise, and correctly discarded.

## Fractal self-similarity

The hologram property (combinable, mergeable, transportable, exchangeable, renderable) is scale-invariant: single node → constellation → full dreamwalk path → sub-path. Any level is a valid, exchangeable unit.

## Path crossing and the cross product

Two dreamwalk paths (over different subsets of a parent) can cross at a shared node — a hub. Crossing yields 4 one-way routes: 2 straight (continue), 2 cross (switch paths). The cross routes are novel: they were not part of either original exploration. A cross path can seed a new table spread — a cross product (novel direction, not a blend) of two normally separate domains. Most cross paths are noise (expected; absorbed by Mode 1's free, no-pressure design); a sub-portion may carry unique meaning and survive into Mode 2. This is the discovery loop: novel cross path → new spread → Mode 1 exploration → Mode 2 resolution → new edges → new paths possible.

## Binswangerization as fertile ground

Grounding is not itself the discovery act. Binswangerized, integrated, grounded knowledge is *fertile soil*: new holographic concepts grown from that ground, grounded from birth, are what produce novel innovation. The ground enables; the new growth produces.

## The base

At its base level the system is just note taking the Luhmann way — atomic notes, links with reasons, characteristics, groups. Emulsification, child holograms, Canvas spread, nD layers, Binswanger grounding: layers built on that simple foundation. The space is technically already there; it needs scale (more nodes, more holograms) to be fully populated, not new infrastructure.

## Honest limits

- Single vault, single user so far: the network/interop vision (intuition packets across human networks) is aspirational. Format portability (Markdown + typed edges) is real; practice portability is not yet demonstrated.
- Automation ceiling: structural verification (breadcrumb import, confidence propagation, derivation validation, consistency/TODO flagging, broken-reference scanning). Everything involving meaning — justifications, evidence, merge decisions — remains human judgment by design.
- The discovery claim is probabilistic: the system creates conditions for novelty; it does not promise it. Measurement of value is rule-22 style: did something new survive translation into a committed card?
