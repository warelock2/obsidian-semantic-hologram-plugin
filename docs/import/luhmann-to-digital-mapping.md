# Luhmann-to-Digital Mapping

**Exported:** 2026-10-22.

---

Principle: replace every paper component with modern tech, **without losing the function Luhmann got out of it**. Function preserved, paper not copied for its own sake.

| Luhmann's paper | Ours | Function preserved |
|---|---|---|
| Slip in pocket | node (`.md` + reveal card) | atomic note |
| Keyword register (Stichwortregister) | full-text search + hover reveal card | entry gate — full-text hits body vocabulary, reveal card shows content before committing to the note |
| Index cross-reference slip | typed incoming `::` breadcrumbs | links carry the reason, retraceable one step |
| Merkmale (characteristics) | atomic `characteristics:` | distinguishing traits, species = differentia only |
| Genus placement | per-genus `groups:` routes with `::` reason | classification with visible route logic |
| Source / evidence slip | source nodes + `lends-gravitas-to` | evidence trail behind gravitas |

Decision captured: plan step 4 (`docs/register.md`) is **obsolete technology** — full-text search strictly dominates a hand-written index (vocabulary mismatch is covered by body search; reveal card beats pulling a slip; zero drift/maintenance). The entry gate is the existing search + root index. Hand-written registers would only regain an edge at curated "start-here" choice among many candidates — negligible at current scale, re-evaluate only if that ever changes.
